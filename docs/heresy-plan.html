2T3: the problem

A fallen rite below 65 is stuck inside the Church.
(The rite positions on the scale are examples. 65 is the default heresy line for Catholicism.)

The game shows it as a normal rite of the Church, and the Pope can’t condemn it until it passes 65. Worse, the game’s yearly drift never pushes a rite past 40, so it might never get there on its own.

3T3: the fix, step by step

1

Detect

Spot the fall as soon as it happens.

The game leaves traces: kind 1 puts a note on the rite it hits, and kind 2 makes its founder a heresiarch. The mod checks every month.
2

Mark

Put the “fallen” mark on the rite. It is now Tier 3.

A hidden mark stored on the rite.
3

Signature heresy

Give it one heretical tenet as a core belief. That alone usually carries it past 65.

The mod adds a little more only if it’s still short. Doctrines like divorce may come along for flavor, but they aren’t needed. See section 4.
4

Condemn

The game now sees a heresy. It drains fervor, and the Pope can condemn it into its own faith.

The game’s normal heresy flow takes over from here.
Never touches Tier 1The main rite, the historic rites and player-led rites can’t fall, so they’re never pushed.
Born clean stays cleanNew Tier 2 rites from normal growth are born in good standing. Only an outbreak makes a rite fall.

4Your idea: more points for weird beliefs

The goal is right: one heretical belief should be enough to make a heresy. That’s also how real heresies worked: one core error, like the Adoptionists, not a random pile of them. The question is where to add the points.

DON’TRaise points on doctrines (divorce…)

A doctrine’s points are the same in every religion. The game can’t give divorce more points only for Catholics.

Side effect: a Muslim or pagan side rite that’s stricter on divorce than its main rite would become heretical in its own faith. The AI’s drift would also change in every religion.

DOUse heretical tenets

A tenet’s points depend on its status in each faith, so they can be big for Catholicism only. The game already works this way:

Tenet in the Catholic faithPoints as a core belief
Adoptionism (Prohibited, weight 2)60
Human sacrifice (Unknown, weight 5)75
Divorce allowed (a doctrine)10
To make it reliable: the mod marks every heretical tenet Prohibited in the Catholic faith. Each one is then worth 30 points or more, and the classic heresies (Adoptionism, Monophysitism, Gnosticism, Simony) are worth 60. The signature heresy is picked from those heavy ones. None of this changes anything for other faiths.

5Is this the best approach?

✓
Yes, with two refinements. It’s the only option that meets all three goals: the game sees a real heresy, nothing changes outside Catholicism, and each heresy has one clear error.

Refinement 2

Keep the rule true forever

The rule: a heretical belief always means the rite is past the line. The game’s yearly drift never touches rites past the line, but the Pope can still pull one back.

Back under 65, still in errorThe mod pushes it past the line again.
Drops every errorIt returns to the Church as Tier 2. History has this too: Felix of Urgell recanted, and Durand of Huesca’s Waldensians returned in 1208.
